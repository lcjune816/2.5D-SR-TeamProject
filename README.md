## MAIN — 맵 제작 도구

맵에 오브젝트를 추가할 때마다 코드를 수정해야 하는 반복 작업을 줄이기 위해 ImGui 기반의 맵 제작 도구를 구현했습니다.

이미지 목록에서 리소스를 선택하고 마우스 피킹을 이용해 원하는 위치에 오브젝트를 배치할 수 있도록 했습니다. 배치한 오브젝트는 위치·회전·크기를 조절하거나 삭제할 수 있습니다.

오브젝트마다 충돌·파괴·애니메이션·포탈 등의 동작 속성을 설정할 수 있으며, 몬스터·보스의 생성 위치와 다음 스테이지로 이동할 위치도 지정할 수 있도록 구성했습니다.

설정한 배치 정보와 동작 속성은 Binary 형식으로 저장하고 다시 불러올 수 있도록 구현하여, 코드를 다시 빌드하지 않고 스테이지 구성을 수정할 수 있게 했습니다.

### 구현 기능

- 이미지 목록을 이용한 배치 리소스 선택
- 마우스 피킹 기반 오브젝트 설치
- 위치·회전·크기 조절 및 삭제
- 충돌·파괴·애니메이션·포탈 속성 설정
- 몬스터·아이템·보스 스포너 배치
- 다음 스테이지와 이동 위치 설정
- 배치 정보 Binary 저장 및 불러오기

## SUB — 천록(CheonLog) 중간 보스

타이머와 상태 전환을 이용하여 공격 순서와 반복 횟수를 제어하고, 플레이어를 향한 조준 공격과 방사형·회전형 탄막 패턴을 구현했습니다.

탄막 공격 과정에서 투사체와 이펙트의 생성·삭제가 반복되며 프레임에 부하가 발생했습니다. 이를 줄이기 위해 활성 풀과 비활성 풀을 분리하고, 수명이 끝난 객체를 삭제하지 않고 비활성화한 뒤 다시 사용하는 객체 풀링 방식을 적용했습니다.

### 구현 기능

- 플레이어 방향을 기준으로 한 조준 투사체
- 방사형 및 회전형 탄막 패턴
- 타이머를 이용한 공격 순서와 반복 횟수 제어
- 투사체 및 이펙트 객체 풀링
- 보스 상태에 따른 패턴 전환

## SUB — 서바이버라이크 미니게임

제한된 공간에서 사방으로 몰려오는 몬스터를 처치하는 5 Wave 방식의 미니게임을 구현했습니다.

Wave가 진행될수록 목표 처치 수가 `10 / 20 / 30 / 40 / 50`으로 증가하도록 구성했으며, 다수의 몬스터가 반복해서 등장하는 구조에 객체 풀링을 적용했습니다.

현재 Wave와 남은 몬스터 수를 UI에 표시하고, 마지막 Wave를 클리어하면 보상을 선택한 뒤 기존 스테이지로 복귀하도록 전체 진행 흐름을 연결했습니다.

### 구현 기능

- 5단계 Wave 진행 관리
- Wave에 따른 몬스터 생성 수 증가
- 몬스터 활성·비활성 풀 관리
- 현재 Wave와 남은 몬스터 수 UI 연동
- 클리어 후 보상 선택
- 기존 스테이지 복귀 처리
